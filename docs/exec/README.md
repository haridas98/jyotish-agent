# Exec Plans

Create one file per independently verifiable milestone.

Start managed work from:

- `2026-06-24-stage-outcomes-and-manager-program.md`
- `2026-06-24-manager-prompts.md`

Each ExecPlan must include:

- purpose;
- baseline commit;
- in scope;
- out of scope;
- validation commands;
- progress;
- decisions;
- outcome;
- next milestone, explicitly out of scope.

Do not start implementation until the active ExecPlan exists and has been read in a fresh session.
