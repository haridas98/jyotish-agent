# Design Principles

## Product Fit

Jyotish Agent is a professional workspace, not a landing page.

## Density

Use high information density where the user compares chart facts, but keep hierarchy clear.

## Layout

- Prefer stable panes, tables, inspectors, and tabs.
- Avoid cards inside cards.
- Avoid decorative bands that do not change workflow clarity.
- Keep first viewport useful: chart, selected facts, and next actions should be visible.

## Visual Language

- Typography, spacing, borders, and alignment carry the interface.
- Avoid one-note palettes.
- Avoid oversized rounded blocks, heavy shadows, and generic SaaS dashboard decoration.
- Use icons only when they clarify repeated actions.

## States

Every designed screen must include:

- loading;
- empty;
- error;
- disabled;
- hover/focus;
- mobile.

## Accessibility

- Visible focus states.
- Sufficient contrast.
- Touch targets usable on mobile.
- Tables must remain keyboard and screen-reader navigable where practical.
