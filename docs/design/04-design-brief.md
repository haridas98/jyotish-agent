# Design Brief

Status: draft, not approved.

## Product Direction

Design a professional Jyotish technical consultation desk.

It should expose calculation facts clearly without feeling like a debug console.

## First Screen To Design

`/charts/:id`

## Visual Direction Requirements

- Calm, intelligent, precise.
- Professional analytical density.
- Strong typography and alignment instead of decoration.
- Restraint: minimal shadows, no decorative gradients, no card-in-card layout.
- Tables and dense facts must remain scannable.
- Mobile must have a deliberate workflow, not only stacked desktop blocks.

## Functional Source Of Truth

- Existing frontend routes and components.
- Current backend/API payloads.
- Existing calculation facts.
- `docs/status/CURRENT.md`.

## Visual Source Of Truth

Not selected yet.

Before implementation, a UX/UI session must produce three distinct directions and one selected visual target.
